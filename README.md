# 객체 인식 및 AR 기반 저시력자 보행 보조 시스템

AI 객체탐지와 AR 기술을 활용한 저시력자를 위한 보조 어플리케이션

---

## 프로젝트 선정 배경

### 시각장애인 현황

국내 시각장애인은 약 25만 명 이상으로, 그 중 **저시력자가 88%(221,426명)**, 전맹이 12%(30,194명)를 차지합니다.
저시력자는 잔존 시력을 보유하고 있어 빛 감지는 가능하지만 형태 인식에 제한이 있으며, 이를 활용하여 일상생활을 하려는 니즈가 있습니다.

### 기존 보조기구의 한계

| 문제 | 내용 |
|------|------|
| 물리/심리적 부담 | 상반신·두부 장애물 탐지 불가, 동적 장애물 탐지 어려움, 흰지팡이에 대한 사회적 낙인으로 비선호 |
| 경제적 부담 | 스마트 지팡이 10~30만 원, 웨어러블 기기 300~400만 원대의 높은 비용 |
| 기존 기기 활용성 | 시각장애인의 스마트폰 보유율은 96.6%(2025년 기준)로 매우 높아 별도 기기 없이 활용 가능 |

### 해결 방향

> 스마트폰 결합형 저비용 HMD를 활용한 **사용자 맞춤 시각 + 음성 보행 보조 시스템**

---

## 기술 스택

- **Unity** — AR 렌더링 및 앱 개발
- **PyTorch / YOLO** — AI 객체 인식 모델 학습
- **Unity Sentis** — 온디바이스 실시간 추론

---

## AI 객체 인식

### 개요

외부 서버 연동 없이 스마트폰 내에서 즉각적으로 장애물을 인식하는 **온디바이스(On-device) 실시간 추론** 방식을 채택합니다.

### 모델 및 학습

| 항목 | 내용 |
|------|------|
| 모델 | YOLO11n (182 Layer, 2.5M params) |
| 학습 데이터셋 | AI Hub "인도 보행영상" (국내 보행 환경 특화) |
| 데이터 규모 | 바운딩 박스 데이터 약 35만 장 |
| 데이터 분할 | Train 80% / Validation 10% / Test 10% |


### 인식 대상

보행 안전 관련 **29종** (사람, 차량, 볼라드, 킥보드, 소화전 등)

## 맞춤형 시각 개선

저시력자의 잔존 시력을 최대한 활용할 수 있도록 개인의 시력 특성에 맞춘 다양한 시각 보조 기능을 제공합니다.

### 기능 목록

| 기능 | 설명 |
|------|------|
| **객체 및 지형 윤곽 표시** | 인식된 객체의 폴리곤 테두리 가시화, 계단·단차 등 지형 경계선 강조 출력 |
| **고대비 출력** | 개인의 시력 특성에 맞춘 대비 강화 모드 제공 |
| **화면 확대** | 멀리 있거나 작은 사물을 쉽게 인지할 수 있도록 확대, 최대 축소 시 광각 렌즈로 넓은 시야 확보 |
| **화면 축소** | 디스플레이 출력 화면 크기를 줄여 제한된 시야 범위 내에서 더 넓은 시각 정보 제공 |
| **대체 출력** | 결손된 중심 시야 영역의 시각 정보를 측면에 재배치하여 시각적 인지 지원 |

## 사용자 피드백

### 실시간 디스플레이 안내

맞춤형 시각개선 모드(고대비, 확대/축소 등)가 적용된 영상을 실시간으로 디스플레이에 출력하여, 사용자의 시각 특성에 맞게 보정된 화면을 통해 주변 장애물 및 환경을 직접 인지할 수 있도록 합니다.

### 실시간 음성 안내 (TTS)

Android TTS API를 활용하여 인식된 객체 정보를 음성으로 즉시 전달합니다.

- **객체 정보 전달**: 인식된 객체의 종류, 상대적 거리, 방향 정보를 음성으로 변환하여 송출
- **데이터 연동**: 연산된 좌표 및 인식 데이터를 기반으로 자연어 형태의 음성 메시지 생성

> 예시: *"자전거"가 "오른쪽" "5m" 앞에 있습니다.*

## 사용 시나리오

1. 앱 설치 후 안드로이드 스마트폰을 HMD(예: Google Cardboard VR)에 장착
2. 스마트폰 음량 조절 버튼으로 시각 보조 기능 ON/OFF 제어
3. 실시간으로 장애물 인식 결과가 화면에 시각화되며, TTS를 통해 음성 안내 수신
